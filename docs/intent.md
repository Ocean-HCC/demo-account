# 意图

本文档记录发起者为什么启动本项目、希望产生什么变化、最终交付什么以及已经确认的边界。方向于 2026-09-24 由发起者确认。

---

## 1. 为什么做

发起者的总目标是：用各种数据做判断，模拟一个人炒股，并不断调整规则直到能盈利，全程不动用真实资金。这个目标拆成两半：一半是"决策"，即选股、择时和规则调优；另一半是"账户"，即资金、下单、撮合、持仓、净值这些账务能力。

发起者已有多个 A 股策略项目（stockAI、signal-forge），每个项目内部各自实现了一套模拟账户。这些能力嵌在各自的业务里，无法被其他项目复用；每启动一个新的策略或 AI Agent 项目，都要再做一遍同样的账务逻辑。

本项目只做"账户"这一半：把模拟账户从策略中抽出来，做成一个独立的模拟券商柜台，让策略程序、AI Agent 和人都能用同一套模拟账户验证交易想法。"决策"这一半留给调用方，例如同目录下正在规划的 QuantificationAgent。

---

## 2. 希望产生什么变化

- 有一个可以独立运行的模拟券商柜台，账务逻辑只实现一次、只维护一处。
- 策略程序或 AI Agent 通过接口就能开户、下单、查询持仓和净值，不必自己实现账务。
- 人通过网页能看到每个账户的资金、持仓、成交和净值曲线，也能手动下单。
- 多个模拟账户可以并行存在，例如每个策略一个账户，便于横向对比表现。

---

## 3. 交付范围

- **形态**：后端 API 服务加网页控制台，放在一个仓库里，本地可运行。
- **市场**：仅沪深 A 股股票和 ETF，按 A 股现行交易规则模拟（T+1、整手、涨跌停、佣金与印花税、滑点等，具体口径见需求）。
- **用户**：单人自用，不做登录注册；支持多个模拟账户并行。

---

## 4. 边界与约束

- 只做模拟，不接入券商，不提供任何真实资金通道。
- 选股、择时判断和规则调优不在本项目内，由调用方完成。
- 不支持沪深 A 股以外的市场。
- 不做多用户平台，没有账号体系和权限。
